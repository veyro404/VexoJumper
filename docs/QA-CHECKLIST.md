- [ ] `dotnet restore` با SDK 10.0.404
- [ ] Release build بدون خطای Compiler
- [ ] بررسی و رفع تمام Warningهای قابل رفع
- [ ] اجرای UI روی Windows 10 و Windows 11
- [ ] بررسی فونت Vazirmatn و RTL با فونت نصب‌شده
- [ ] آزمایش Ping موفق، Timeout، مقصد نامعتبر و لغو عملیات
- [ ] DNS Lookup دامنه معتبر، دامنه نامعتبر و شبکه بدون اینترنت
- [ ] تغییر DNS دستی روی رابط آزمایشی با تأیید کاربر

- [ ] بررسی نام رابط شامل فاصله/کاراکترهای غیرلاتین
- [ ] تغییر اتصال Wi-Fi/Ethernet و قطع/وصل شبکه
- [ ] مقایسه شمارنده‌ها با آمار سیستم‌عامل
- [ ] بررسی مصرف CPU/RAM در حالت Idle
- [ ] بررسی بسته‌شدن صحیح برنامه و لغو عملیات جاری
