## ✨ درباره Vexo Jumper

Vexo Jumper یک برنامه دسکتاپ ویندوزی برای **مدیریت و عیب‌یابی ساده‌تر شبکه** است. هدف پروژه این است که ابزارهای کاربردی شبکه را در یک محیط یکپارچه، فارسی و خوانا قرار دهد؛ بدون اینکه کاربر مجبور باشد بین فهرست‌های طولانی رابط‌های شبکه و ابزارهای مختلف جابه‌جا شود.

در نسخه 1.2.0، برنامه رابط شبکه فعال را با کمک مسیر IPv4 انتخاب‌شده توسط ویندوز تشخیص می‌دهد، اطلاعات اتصال را نمایش می‌دهد و ابزارهایی مانند Ping، DNS Lookup، پایش ترافیک و پروفایل‌های آماده DNS را در اختیار کاربر قرار می‌دهد.

> **Vexo Jumper قرار نیست پیچیده باشد؛ ابزارهای ضروری شبکه، در یک محیط ساده و قابل فهم.**

## 🚀 دریافت و اجرا

### روش سریع — دریافت نسخه آماده

1. وارد صفحه [آخرین انتشارها (Releases)](https://github.com/veyro404/VexoJumper/releases/latest) شو.
2. فایل `VexoJumper-win-x64.zip` را از بخش **Assets** دریافت کن.
3. فایل ZIP را در یک پوشه استخراج کن.
4. فایل `VexoJumper.exe` را اجرا کن.

نسخه Self-contained منتشر می‌شود؛ بنابراین برای اجرای بسته انتشار، نصب جداگانه .NET Runtime معمولاً لازم نیست. برای تغییر تنظیمات DNS ممکن است دسترسی Administrator لازم باشد.

## 🧩 قابلیت‌ها

| قابلیت | توضیح |
|---|---|
| 🧭 تشخیص خودکار شبکه | شناسایی رابط IPv4 متناظر با مسیر انتخاب‌شده توسط ویندوز؛ بدون نیاز به انتخاب دستی از فهرست بلند |
| 🌐 اطلاعات اتصال | نمایش نام رابط، نوع اتصال، IPv4، Gateway و DNSهای پیکربندی‌شده |
| 📡 Ping | ارسال درخواست ICMP به IP یا دامنه و نمایش تعداد پاسخ‌های موفق و میانگین زمان پاسخ |
| 🔎 DNS Lookup | دریافت آدرس‌های دامنه با استفاده از DNS تنظیم‌شده در ویندوز |
| ⚙️ پروفایل‌های DNS | انتخاب سریع سرویس‌های DNS آماده و پرکردن خودکار آدرس‌های اصلی و جایگزین |

| 📊 پایش ترافیک | نمایش نرخ دریافت و ارسال بر اساس شمارنده‌های رابط شبکه ویندوز |
| 🎨 رابط کاربری | محیط تیره، فارسی و راست‌چین با کارت‌های خوانا و انیمیشن‌های ظریف |

## 🛠️ ساخت از سورس

### 1. دریافت مخزن

```powershell
git clone https://github.com/veyro404/VexoJumper.git
cd VexoJumper
```

### 2. بررسی محیط توسعه

برای ساخت پروژه به Windows و .NET SDK 10 نیاز داری. نسخه SDK مورد انتظار اسکریپت فعلی `10.0.404` است.

```powershell
dotnet --info
```

### 3. Build و Publish

اسکریپت زیر Restore، Build با تبدیل Warning به Error و انتشار Self-contained برای Windows x64 را انجام می‌دهد:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\build-and-publish.ps1 -SkipRun
```

فایل خروجی در مسیر زیر قرار می‌گیرد:

```text
artifacts/win-x64/VexoJumper.exe
```

برای Build معمولی بدون اسکریپت:

```powershell
dotnet restore .\VexoJumper.sln
dotnet build .\VexoJumper.sln -c Release
```

## 🧪 محدوده قابلیت‌ها و محدودیت‌های فعلی

برای اینکه انتظارها دقیق و شفاف باشند، موارد زیر را در نظر بگیر:

- Ping از ICMP استفاده می‌کند؛ بعضی مقصدها پاسخ ICMP را مسدود می‌کنند.
- DNS Lookup از Resolver پیکربندی‌شده در ویندوز استفاده می‌کند؛ این قابلیت بنچمارک مستقل و هم‌زمان DNS Providerها نیست.
- پایش ترافیک از شمارنده‌های رابط شبکه ویندوز استفاده می‌کند و ممکن است ترافیک LAN را نیز دربر بگیرد؛ این مقدار لزوماً با حجم محاسبه‌شده توسط ISP برابر نیست.
- تشخیص رابط فعال با انتخاب آدرس محلی مسیر UDP توسط ویندوز انجام می‌شود. در سیستم‌هایی با چند مسیر، VPN یا Policy Routing سفارشی، انتخاب نهایی تابع جدول مسیریابی ویندوز است.
- تست سرعت واقعی دانلود/آپلود با سرور تست، Jitter و Packet Loss در نسخه فعلی پیاده‌سازی نشده‌اند.
- Traceroute، Reverse DNS، TCP/TLS diagnostics، IP عمومی، تفکیک مصرف بر اساس فرایند، System Tray و نصب‌کننده اختصاصی در محدوده نسخه فعلی نیستند.
- تغییر DNS ممکن است به مجوز Administrator نیاز داشته باشد. اگر عملیات ناموفق بود، برنامه را با دسترسی مناسب اجرا و دوباره امتحان کن.
