## ✨ Vexo Jumper چیست؟

Vexo Jumper VPN یک ابزار دسکتاپ برای ویندوز است که اتصال VPN و ابزارهای روزمره‌ی مدیریت و عیب‌یابی شبکه را در یک محیط یکپارچه جمع می‌کند. به‌جای بازکردن چند ابزار مختلف، وضعیت اتصال، تونل VPN، DNS، پینگ و مصرف شبکه را از یک رابط فارسی و مرتب دنبال کن.

نسخه‌ی **1.7.0** علاوه بر کلاینت VPN مبتنی بر **sing-box**، دریافت و به‌روزرسانی فهرست سرورها از سرویس مدیریت کانفیگ پروژه، سنجش دسترسی سرورها، تلاش برای اتصال به گزینه‌های برتر، بررسی واقعی اینترنت از داخل تونل و سازوکار به‌روزرسانی برنامه را ارائه می‌کند.

> طراحی شده تا تجربه‌ی شبکه ساده‌تر و قابل‌فهم‌تر باشد؛ نه اینکه با پیام‌های مبهم و تنظیمات پیچیده سردرگمت کند.

## 🚀 دریافت و شروع سریع

### نسخه آماده ویندوز

1. به صفحه‌ی [آخرین نسخه‌ها در GitHub](https://github.com/veyro404/VexoJumper/releases/latest) برو.
2. فایل ZIP نسخه‌ی ویندوز را از بخش **Assets** دریافت و استخراج کن؛ یا اگر فایل Setup در همان انتشار ارائه شده بود، نصب‌کننده‌ی x64 را اجرا کن.
3. فایل `VexoJumperVPN.exe` را اجرا کن.
4. برای ساخت تونل VPN، درخواست دسترسی Administrator ویندوز را تأیید کن.
5. در صفحه‌ی VPN روی دکمه‌ی مرکزی بزن و منتظر تأیید اتصال واقعی بمان.

نسخه‌ی منتشرشده‌ی برنامه به‌صورت Self-contained ساخته می‌شود و به نصب جداگانه‌ی .NET Runtime نیاز ندارد. برای اولین اتصال VPN، برنامه ممکن است موتور sing-box و فایل درایور Wintun را از منابع رسمی دریافت کند؛ بنابراین در راه‌اندازی اولیه دسترسی اینترنت لازم است.

## 💎 قابلیت‌ها

### 🛡️ VPN با موتور sing-box

- ایجاد تونل TUN در ویندوز با موتور sing-box.
- پشتیبانی از قالب‌های متداول لینک کانفیگ در parser برنامه؛ از جمله VLESS، VMess، Shadowsocks، Trojan، Hysteria2 و TUIC. فعال‌بودن هر پروتکل به پشتیبانی و کامل‌بودن اطلاعات همان کانفیگ وابسته است.
- دریافت فهرست کانفیگ‌ها از سرویس مدیریت کانفیگ پروژه و نگهداری نسخه‌ی محلی برای زمان‌هایی که سرویس در دسترس نیست.
- بررسی دسترسی TCP سرورها و اولویت‌بندی بر اساس زمان پاسخ؛ سپس تلاش برای اتصال به گزینه‌های برتر.
- اعلام اتصال فقط پس از اجرای موتور و موفقیت بررسی HTTPS از مسیر تونل.
- پایش سلامت تونل و تلاش خودکار برای اتصال مجدد در صورت قطع‌شدن موتور یا از دسترس خارج‌شدن تونل.
- بستن فرایند فرزند VPN همراه برنامه با Windows Job Object برای کاهش احتمال باقی‌ماندن پردازش تونل پس از بسته‌شدن اجباری برنامه.
- نمایش وضعیت اتصال، تأخیر، سرعت دریافت/ارسال و مدت اتصال.

### 🌐 مدیریت DNS و شبکه

- تشخیص خودکار رابط شبکه‌ی فعال بر اساس مسیری که ویندوز انتخاب کرده است.
- نمایش نام رابط، نوع اتصال، IPv4، Gateway و DNSهای فعلی.
- انتخاب پروفایل DNS و واردکردن DNS اصلی و جایگزین.
- اعمال DNS با تأیید کاربر و بازگرداندن تنظیمات به حالت خودکار DHCP.
- نمایش تأخیر پاسخ DNSهای آماده و DNS سفارشی در صفحه‌ی شبکه.
- پروفایل‌های Electro، Shecan، Begzar، Google Public DNS، Cloudflare، Quad9، OpenDNS، AdGuard، Safe DNS و NTT.

### 🧰 ابزارهای عیب‌یابی

| ابزار | کاربرد |
|---|---|
| تست Ping | بررسی پاسخ ICMP یک IP یا دامنه و نمایش زمان پاسخ |
| DNS Lookup | تبدیل دامنه به IP با DNS تنظیم‌شده در ویندوز |
| Smart Diagnosis | بررسی چندمرحله‌ای رابط شبکه، Gateway، اینترنت و DNS |
| DNS Benchmark | مقایسه‌ی زمان پاسخ DNSهای منتخب در شبکه‌ی فعلی |
| Quick Fix | اجرای ابزارهای تعمیر سریع مانند پاک‌کردن DNS Cache و بازنشانی Winsock/IP (با توجه به عملیات انتخابی) |
| Live Traffic Monitor | نمایش سرعت لحظه‌ای دریافت و ارسال و آمار مصرف رابط شبکه |
| Connection History | ثبت رویدادهای اتصال، VPN و عملیات شبکه |

### ✨ تجربه‌ی کاربری

- رابط تیره، راست‌چین و فارسی با طراحی شیشه‌ای و جزئیات نئونی.
- دکمه‌ی مرکزی سه‌بعدی با وضعیت‌های قطع، اتصال و وصل.
- اجرای پس‌زمینه در System Tray با امکان بازکردن دوباره، قطع VPN و خروج کامل.
- به‌روزرسانی درون‌برنامه‌ای با دانلود مرحله‌ای، امکان ادامه‌ی دانلود، بررسی SHA-256 و پشتیبانی از انتشارهای اجباری.

## 🔄 سیستم به‌روزرسانی نسخه 1.7.0

برنامه وضعیت نسخه‌های جدید را از سرویس به‌روزرسانی پروژه بررسی می‌کند. در صورت انتشار نسخه‌ی جدید، امکان مشاهده‌ی تغییرات و دریافت آن از داخل برنامه فراهم می‌شود. فایل دریافتی و فایل اجرایی با SHA-256 بررسی می‌شوند و نصب نسخه‌ی جدید با فرایند جایگزینی و تلاش برای بازگشت در صورت خطا انجام می‌شود. انتشار اجباری نیز توسط مدیر سرویس قابل‌علامت‌گذاری است.

## 🧱 ساخت از سورس

پیش‌نیاز: ویندوز و **.NET SDK 10.0.404** (نسخه‌ی مورد انتظار اسکریپت ساخت).

```powershell
git clone https://github.com/veyro404/VexoJumper.git
cd VexoJumper
Set-ExecutionPolicy -Scope Process Bypass -Force
.\build-and-publish.ps1 -Runtime win-x64 -SkipRun
```

فایل خروجی در مسیر زیر ساخته می‌شود:

```text
artifacts\win-x64\VexoJumperVPN.exe
```

اسکریپت، Restore، ساخت Release با تبدیل Warningها به Error و انتشار Self-contained تک‌فایلی را انجام می‌دهد. برای ساخت سریع Setup، ابتدا خروجی بالا را بساز و سپس اجرا کن:

```powershell
.\build-installer.ps1
```

این اسکریپت Inno Setup 6 را پیدا می‌کند و فایل `artifacts\installer\VexoJumperVPN-Setup-1.7.0-x64.exe` را می‌سازد. کامپایل دستی نیز با بازکردن `installer\VexoJumperVPN.iss` در Inno Setup Compiler ممکن است.

## 🔐 حریم خصوصی و نکات امنیتی

- تغییر DNS پس از تأیید صریح کاربر انجام می‌شود.
- برنامه برای ساخت تونل VPN به دسترسی Administrator نیاز دارد.
- فهرست کانفیگ و اطلاعات به‌روزرسانی از سرویس‌های آنلاین پروژه دریافت می‌شوند؛ برای استفاده از این قابلیت‌ها اتصال اینترنت لازم است.
- فایل‌های موتور و درایور از منابع رسمی دریافت می‌شوند؛ برای Wintun بررسی SHA-256 در کد وجود دارد.
- اطلاعات عملیاتی و خطاها در مسیر `%LOCALAPPDATA%\VexoJumper\logs` ثبت می‌شوند. پیش از اشتراک‌گذاری لاگ، اطلاعات حساس احتمالی را بررسی و حذف کن.
- VPN به‌تنهایی ناشناس‌بودن کامل، امنیت دستگاه، سرعت مشخص یا دسترسی همیشگی به هر وب‌سایت را تضمین نمی‌کند. کیفیت اتصال به سرور، شبکه، اپراتور و سیاست‌های مقصد وابسته است.

## ⚠️ محدودیت‌ها و انتظارات واقع‌بینانه

- تست Ping به ICMP متکی است؛ بعضی مقصدها پاسخ ICMP را مسدود می‌کنند.
- DNS Benchmark و پینگ DNS، نتیجه‌ی همان شبکه و همان لحظه‌اند و تضمین نمی‌کنند یک DNS همیشه سریع‌تر باشد.
- سرعت ترافیک از شمارنده‌های رابط شبکه‌ی ویندوز خوانده می‌شود و ممکن است تمام ترافیک LAN را هم شامل شود.
- دسترسی‌پذیری TCP به‌تنهایی تضمین‌کننده‌ی کارکرد VPN نیست؛ برنامه بعد از راه‌اندازی تونل، دسترسی HTTPS را نیز بررسی می‌کند.
- دسترسی و پایداری سرورهای فهرست‌شده در سرویس کانفیگ خارج از کنترل برنامه است.
- تغییر DNS یا تعمیر Winsock/IP ممکن است اتصال فعلی را موقتاً قطع کند و به مجوز مدیر نیاز داشته باشد.
